## 🏆 National Competitions & Milestones
* ⚔️ **5th Position — National RoboWar Competition (Dehradun Campus):** High-torque combat robot with dual Cytron & BTS7960 43A motor drives, armored chassis, 3S/4S LiPo power distribution, and 2.4 GHz AFHDS radio control.
* 🏎️ **6th Position — National RoboRace Competition:** High-speed differential drive vehicle with tuned PWM steering curves and DFPlayer audio telemetry.
* 🎓 **STEM Workshops:** 200+ engineering students trained on microcontrollers, embedded C++, sensor integration, and PCB prototyping.

## 🚀 Club Repository Directory

### ⚔️ Combat & Competition Robots
* [**toing-bot-esp32-bts7960-rover**](https://github.com/GEHU-Robotics-Club/toing-bot-esp32-bts7960-rover) — 5th-place national RoboWar combat robot built with an ESP32 and dual 43A BTS7960 motor drivers.
* [**arduino-bluetooth-robot-car-dfplayer**](https://github.com/GEHU-Robotics-Club/arduino-bluetooth-robot-car-dfplayer) — 6th-place RoboRace vehicle with differential drive and voice telemetry via a DFPlayer Mini module.
* [**gehu-robotics-club-showcase**](https://github.com/GEHU-Robotics-Club/gehu-robotics-club-showcase) — Complete documentation, telemetry logs, and circuit diagrams for university competition rovers.

### 🧠 Autonomous Navigation & Edge AI
* [**esp32-face-gesture-robot**](https://github.com/GEHU-Robotics-Club/esp32-face-gesture-robot) — Mobile robot that tracks human face angles in real time using Python OpenCV and Wi-Fi telemetry to ESP32.
* [**arduino-multi-sensor-navigation-bot**](https://github.com/GEHU-Robotics-Club/arduino-multi-sensor-navigation-bot) — Self-driving obstacle avoidance robot fusing ultrasonic ping timing and infrared proximity sensors.
* [**ir-remote-obstacle-avoiding-robot**](https://github.com/GEHU-Robotics-Club/ir-remote-obstacle-avoiding-robot) — Multi-mode autonomous obstacle avoider with manual override using standard 38kHz TV remote signals.

### 📡 Wireless Telemetry & Mobile Control
* [**esp32-inbuilt-bluetooth-rover-app**](https://github.com/GEHU-Robotics-Club/esp32-inbuilt-bluetooth-rover-app) — Smartphone-controlled rover running bare-metal PWM motor control via ESP32 Classic Bluetooth SPP.
* [**nrf24l01-basic-rf-motor-car**](https://github.com/GEHU-Robotics-Club/nrf24l01-basic-rf-motor-car) — Custom 2.4 GHz handheld remote and receiver car built using low-power NRF24L01+ transceivers.
* [**wifo-2.0-ble-dual-app-controller**](https://github.com/GEHU-Robotics-Club/wifo-2.0-ble-dual-app-controller) — Low-power BLE multi-channel automation board supporting dual concurrent mobile app connections.
* [**wifo-basic-ble-system**](https://github.com/GEHU-Robotics-Club/wifo-basic-ble-system) — Single-channel Bluetooth Low Energy peripheral for wireless relay switching from iOS/Android.
